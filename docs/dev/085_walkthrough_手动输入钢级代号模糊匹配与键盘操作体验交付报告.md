# 085 研发走查报告：手动输入钢级代号多维模糊匹配与键盘操作体验交付报告

## 1. 业务痛点与目标

在材料牌号消歧（`UNKNOWN_GRADE`）抽屉中，当系统推荐列表未命中时，质检员需要使用“手动输入其他标准钢级代号”。
原交互为一个普通的纯文本输入框，质检员容易因大小写、短横线或混淆统一代号与化学式导致输入无效。
本次迭代实现基于当前生效标准的动态多维模糊匹配，兼具键盘导航与兜底自由度。

---

## 2. 方案落地与架构

### 2.1 规则切片元数据直通
- 后端 `FileRuleStore.listAvailableStandards()` 在装配概览时补充 `slice_details`（包含主牌号、统一代号、全称与别名）；
- 接口 `/api/standards` 原生下发，客户端 `WaterfallWorkbench` 无缝将已加载数据直通给 `HitlDrawer`，无需任何冗余网络请求。

### 2.2 多维模糊检索工具 (`grade-fuzzy-matcher.ts`)
- `buildGradePool`：优先按当前批次生效的标准代号集合筛选切片，若未命中则退化为全库标准，并按主牌号去重；
- `searchFuzzyGrades`：支持统一代号完全/前缀/包含匹配、化学式子串匹配、别名包含匹配与归一化字符匹配，按相关性打分降序排列。

### 2.3 抽屉组件交互重构 (`HitlDrawer.tsx`)
- 输入框集成绝对定位下拉浮层（带 max-height、细滚动条、别名命中标签、标准标签）；
- 支持键盘 `ArrowUp` / `ArrowDown` 循环切换高亮、`Enter` 确认选择、`Escape` / 点击外部关闭浮层及一键清空按钮；
- 选中后回填标准全称（如 `022Cr17Ni12Mo2 (S31603)`），提交时向引擎传递规范主牌号；未选中时保留自由输入提交权。
