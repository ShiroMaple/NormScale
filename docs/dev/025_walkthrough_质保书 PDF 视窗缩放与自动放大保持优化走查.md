# 质保书 PDF 视窗缩放与自动放大保持优化走查

## 改动概要

1. **PDF 缩放上限与控制优化**：
   - 缩放范围由 `75% ~ 175%` 放宽至 **`50% ~ 300%`**；
   - 步长调整为标准 **`25%`**（点 `+` 连续放大：125% -> 150% -> 175% -> 200% -> ... -> 300%）；
   - 中间百分比文字支持**点击一键瞬间恢复为 100%**；
   - 移除了容器 `maxWidth: '100%'` 约束，在大比例下配合 `overflow-x-auto` 真实横向展开，无任何裁切。

2. **自动聚焦放大 200% 保持与退出重构**：
   - **移开鼠标不再自动回缩**：鼠标离开字段或 BBox 后，依然稳稳锁定 200% 聚焦视角，质检员可直接将鼠标移至右侧输入框核对并打字录入数据；
   - **平滑目标切换**：当光标移入另一个检验项时，视窗平滑转移至新字段坐标；
   - **显式便捷退出**：
     - 左上角放大徽标常驻提供 **`退出放大 (ESC)`** 按钮，点击即可退出放大；
     - 全局键盘监听 **`ESC`** 键，按下即可瞬间恢复常规 100% 比例；
     - 切换页码或切换批次时，自动重置放大状态。

## 验证结果

- **TypeScript 严格类型检查**：`pnpm typecheck` (`tsc --noEmit`) 0 报错通过。
- **本地服务状态**：`pnpm dev` 持续运行中，实时热更新生效。
