# 执行标准列“指标主显 + 来源垂直下沉”排版重构交付报告

针对用户指出的“当前长文本合并效果不佳、横向空间更为宝贵、行高允许适度拉高”问题，经过 `/grill-me` 逐步决策对齐，已完成全景合规比对矩阵关键排版重构与列宽优化。

---

## 一、本次重构对齐决策与设计全貌

| 维度 | 调整前 (横向长文本) | 调整后 (指标主显 + 来源垂直下沉) |
|---|---|---|
| **排版模型** | 单行横向拼接（`NB/T 47019.5-2021 + GB/T 13296-2023: ≤ 0.08 % ★`），横向宽度被拉长到近 300px，严重侵占其他列空间。 | **首行指标主显，标准来源垂直下沉**。纵向延展利用垂直空间，单行宽度仅需 ~140px。 |
| **一致项呈现 (如 C、Si、Mn 等)** | 多个长标准代号横向连写。 | **首行大字加粗指标**：`≤ 0.08 % ★`；<br>**下方垂直堆叠标准药丸**：每标独立一行（如 `NB/T 47019.5-2021`、`GB/T 13296-2023`），**不重复输出数字**，干净利索。 |
| **剪刀差/加严项 (如伸长率 A)** | 展开后长标签占用大量横向空间。 | **首行显示严苛主导控制指标**：`≥ 40 % ★`；<br>**下方垂直展开各标要求明细**：`NB/T 47019.5-2021: ≥ 40 % ★`（金色高亮）与 `GB/T 13296-2023: ≥ 35 %`。 |
| **标准列与判定逻辑列宽分配** | 标准列强制 `min-w-[220px]`，判定逻辑列 `min-w-[260px]`。 | 标准列压缩至 `min-w-[170px] w-48`；节省的 50px 空间全部补给【判定逻辑】(`min-w-[300px]`)，极大缓解文本换行压力。 |
| **表格行对齐** | 默认居中对齐，拉高后视觉起伏。 | 统一增加 `align-top` 顶部对齐，多行堆叠时整齐划一。 |

## 二、代码变更清单

### 1. 表头列宽重构与单元格顶部对齐 ([`src/components/WaterfallWorkbench.tsx`](file:///c:/Users/gaoft/Documents/CodeSpace/NormScale/src/components/WaterfallWorkbench.tsx))
- 将表头【执行标准要求 / 条款规范】列从 `min-w-[220px]` 调整为 `min-w-[170px] w-48`；
- 将【判定逻辑 / 审核说明】列从 `min-w-[260px]` 扩充至 `min-w-[300px]`；
- 表格数据行 `<tr>` 补充 `align-top`，多行元素自然对齐顶端。

### 2. 执行标准要求单元格“指标主显+来源垂直下沉”渲染算法
- **一致项分支**：
  - 提取出统一指标 `firstReq` 并以加粗 `text-[12px]` 居顶显示；
  - 遍历 `evals` 垂直分行渲染微型药丸 `span`（宽度 ~140px，深灰微边框背景），只列标准代号；
- **剪刀差/独占分支**：
  - 居顶加粗显示 `governingEval.requirement_text` 与金色 `★`；
  - 下方垂直分行罗列各标准具体指标，加严主导标使用琥珀黄底色高亮。
