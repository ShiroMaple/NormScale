# 步骤 3: 比对执行标准 - 页面布局重构与全景合规比对矩阵实施方案

本方案旨在全面升级“步骤 3: 比对执行标准”的视觉架构与交互体验。彻底消除原方案“左侧实测快照 + 右侧比对表”造成的数据重复与视线跳跃，建立工业级清晰的**全景合规比对矩阵（Master Compliance Matrix）**，并完善标准/牌号切换与三态人机协同（HITL）决策流。

---

## 核心设计与重构内容

### 1. 顶部上下文与三态判定决策带（上部 ~25%）
- **左卡片：锁定规则切片与追溯元数据**
  - 展示：锁定执行标准（如 `GB/T 13296-2023 / NB/T 47019.5-2021`）、钢级牌号（如 `S32168 (06Cr18Ni11Ti)`）、几何规格（如 `OD 15.0mm × WT 0.8mm`）、冶炼炉号（`YX2602-2207`）与热处理装炉号（`Z26022C`）；
  - **支持标准/牌号切换（Manual Override）**：
    - 提供【切换标准/钢级】轻量按钮；
    - 点击唤出规则选择浮层，支持从收录的 31 个钢级规则切片（S30408、S31603、S32168、S34778 等）中快速重选；
    - 重选后标记为 `人工重置规则 (Manual Override)`，触发合规判定即时重算。
- **右横幅：综合判定看板与人机协同（HITL）三态流转**
  - **PASS 全项合格（翡翠绿）**：所有强制项指标符合，提供【特批放行】、【拒收】、【审批结果】以及底部主按钮【比对通过，生成质检报告】；
  - **FAIL 一票否决不合格（绯红）**：存在超标项（如硫磷超标或延伸率不达标），醒目标红警告，提供【生成不合格拒收单】；
  - **HITL 待质检员协同裁决（琥珀金）**：存在替代条款（如涡流替代水压）或微小公差偏差，列出待审议要点，支持行内或横幅一键【特批放行】、【一票否决】与【唤出协同抽屉】。

### 2. 全景合规比对矩阵（Master Compliance Matrix，下部 ~75%）
- **彻底消除左右分栏的数据重复**：将步骤 2 确认的所有解析结果直接作为比对表中的【报告测量值】列，与【执行标准要求】紧密同行相邻并排！
- **动态分类页签（Filter Tabs）**：
  - `全部比对项 (All)`
  - `化学成分 (Chemical)`
  - `力学性能 (Mechanical)`
  - `工艺与成型 (Process)`
  - `金相组织 (Metallographic)`
  - `耐腐蚀试验 (Corrosion)`
  - `无损探伤 (NDT)`
  - `几何尺寸与表面 (Dimensions/Surface)`
  - `非标与扩展协议 (Additional/Fallback)`
- **全景表格列结构**：
  1. `类别`（如 化学成分、力学性能、工艺试验、非标兜底，带微型彩色胶囊）；
  2. `检验项目 / 指标`（如 `C 含量`、`抗拉强度 Rm`、`压扁试验`、`合同编号`）；
  3. `报告测量值 / 实际结果`（突出加粗高亮展示，数值型带单位，定性条款带试验结果）；
  4. `执行标准要求 [Min, Max] / 条款规范`（直接相邻！如 `≤ 0.08 wt%`、`≥ 520 MPa`、`间距 H=(1+0.09)S/(0.09+S/D) 无裂纹`）；
  5. `偏差量 / 吻合度`（数值型精准计算偏离极值的绝对差，定性条款显示 `完全符合`）；
  6. `判定状态`（`✓ PASS` / `✗ FAIL` / `⚠️ HITL` / `ℹ️ 仅供参考`）；
  7. `规则依据 / 判定逻辑`（展示判定逻辑，如 AST 动态公式 `$Ti \ge 5 \times (C+N)$` 代入过程、免检说明或长尾协议提示）。

### 3. 长尾元数据与超出 Schema 预期数据的呈现
- 步骤 2 捕获的 `additional_identifiers`（如合同号、母卷号、特种设备制造许可证 TS 编号等）在比对矩阵中归入 `非标与扩展协议` 分类；
- 状态标识为 `ℹ️ INFORMATIONAL (仅供参考)`；
- 依据列标注 `非国标强制指标 (来自技术协议 / 扩展池)`，既确保信息 100% 完整继承，又避免误报打断主流程。

## 验证计划

### 1. 自动化测试与类型检查
```bash
pnpm typecheck
pnpm test
```

### 2. 交互实机验证
1. 访问 `http://localhost:3000/` 并切换至“步骤 3: 比对执行标准”；
2. 验证顶部卡片完整展示双炉号（原材料炉号与热处理装炉号）与规格；
3. 点击【切换标准/钢级】，测试从 S32168 切换至 S30408 或 S31603，验证比对大表与判定结果即时联动重算；
4. 检查全景合规比对大表：
   - 验证化学 9 元素、拉伸 3 项、维氏硬度、压扁、扩口、晶间腐蚀、涡流检测等各项是否整齐平铺，无左右分栏重复；
   - 验证测量值与标准要求同表相邻，偏差量与状态一目了然；
   - 验证动态 AST 公式 `$Ti \ge 5 \times (C+N)$` 的推演过程展示；
   - 验证非标兜底项以 `ℹ️ 仅供参考` 优雅呈现。
