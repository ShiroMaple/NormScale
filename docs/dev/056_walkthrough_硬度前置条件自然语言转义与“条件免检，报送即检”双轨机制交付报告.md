# 硬度前置条件自然语言转义与“条件免检，报送即检”双轨机制交付报告

根据用户对硬度试验核验逻辑的深入探讨与实施指示，本项目彻底升级了合规核验引擎的前置条件（`trigger_condition`）调度机制，实现了面向质检员的人性化业务自然语言转义，并落地了工业标准的“**条件免检，报送即检 (Conditional Exemption, but Verify if Reported)**”双轨调度闭环。

---

## 一、用户关切问题与设计背景

1. **自然语言如何理解原提示“前置条件【ctx.header.dimensions.wall_thickness_mm >= 1.7】未激活，该检验项自动跳过”？**
   - **技术代码视角**：这是规则引擎在执行布尔表达式判定，表示根据质保书提取出的管壁厚度（$WT=0.8\text{ mm}$），未满足该检验项启动的阈值（$1.7\text{ mm}$），因此引擎将该规则标记为 `SKIPPED`；
   - **业务标准视角**：国家标准 `GB/T 13296` 与承压行业标准 `NB/T 47019.5` 明确规定，薄壁管（壁厚 $< 1.7\text{ mm}$）免测硬度，因为常规大载荷压痕（HRB/HBW）施加在薄壁管上会直接打透或受底部铁砧垫板影响产生假硬度。因此在法律法规层面上，该换热管属于**法定免检**范围。
2. **结合测试报告原件来看，这项规则直接跳过应用得合适吗？**
   - **不完全合适**：原件厂家（镇海石化管件供方）为了满足订货协议、证明材料热处理固溶充分，采用了专用于薄壁管的小负荷维氏硬度（`HV1`，1kgf 载荷）进行 6 点测试（测得 132~145 HV1，均值 139.3，标准限值 $\le 200\text{ HV}$），并如实打印在质保书中。
   - 若系统机械地以壁厚 $< 1.7\text{ mm}$ 盲目跳过：
     - **浪费质量证据**：供方明明付出了检验成本并提供了证明质量良好的关键数据，质检员看到的却是“不适用/自动跳过”；
     - **存在质安全隐患**：如果某批薄壁管材料由于固溶不充分产生严重异常硬化（例如测得 250 HV > 200 HV），若引擎因壁厚薄直接跳过，将导致致命质量安全隐患被漏检！

## 二、核心改造与落地清单

### 1. 前置条件业务自然语言转义器 (`src/engine/missing-scanner.ts`)
- 新增 `formatConditionHumanText` 辅助函数；
- 将底层代码变量名（如 `ctx.header.dimensions.wall_thickness_mm >= 1.7`）智能解析转义为面向质检员与用户的业务自然语言：
  `壁厚需 ≥ 1.7mm (实际壁厚: 0.8mm)`；
- 彻底告别暴露代码变量名，增强专业度。

### 2. “条件免检，报送即检”双轨调度引擎 (`src/engine/core.ts`)
在单规则评估调度器 `evaluateSingleRule` 中构建双轨分流：
- **场景 A（前置未激活，且供方未报送）**：
  - 评定为 `SKIPPED`（法定免检）；
  - 输出明确说明：“前置条件【壁厚需 ≥ 1.7mm (实际壁厚: 1.5mm)】未激活（法定免检），供方未报送实测数据，该检验项自动跳过”；
- **场景 B（前置未激活，但供方主动报送实测数据）**：
  - 自动激活“**报送即检**”机制，放行进入实质核验器（`evaluateOrChoiceGroup` 等）；
  - **若实质合格（PASS）**：评定为 `PASS`，详细文案说明：“标准要求壁厚需 ≥ 1.7mm 时强制考核，当前规格法定免检（豁免）；供方主动报送实测数据且检验合格，予以认可通过”；
  - **若实质不合格（FAIL）**：评定为 `FAIL`，准确拦截质量超标隐患：“规格虽属于法定免检范围，但供方主动报送的实测数据超出标准限值要求，判定不合格”。

### 3. 多选一硬度标尺防呆隔离 (`src/engine/logic-evaluator.ts`)
- 改进 `evaluateOrChoiceGroup` 候选匹配机制；
- 智能识别实测原始文本与单位中的硬度标尺标识（`HV` / `HRB` / `HBW`）；
- 避免质保书报送的 `143、145... HV1` 错误跨标尺拿去与 HRB $\le 90$ 比对，杜绝出现荒谬的“HRB 超标”误判。

### 4. 规格复合表达式提取增强 (`src/app/api/audit/submit/route.ts`)
- 扩展尺寸正则表达式，支持形如 `OD 15.0mm × WT 0.8mm`、`Φ15.0×0.8` 等工程标记的精准解构；
- 将顿号隔开的多点硬度读数计算综合平均值（如 6 点平均值 139.3 HV），并标记子属性为 `HV`。
