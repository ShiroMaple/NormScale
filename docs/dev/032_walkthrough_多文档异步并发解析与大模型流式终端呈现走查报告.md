## 核心技术与设计亮点

1. **多文档异步并发调度 (`useDocumentParser`)**：
   - 设定并发上限 `MAX_CONCURRENCY = 2`；
   - 自动维护任务队列、进度时序、字符分片打字机流与计时器；
   - 一旦某份文档完成，自动从等待队列拉取下一份启动，实现高吞吐平滑流水线。

2. **Session 级累计 Token 指标计算**：
   - 标题行右侧展示全 Session 累计输入/输出 Token 及总解析耗时，随各文档并发完成实时向上累加。

3. **零 Emoji 纯净工业级视觉规范**：
   - 全界面所有徽标与指示器严格使用 **Material Symbols Outlined** 图标（`memory`、`timer`、`check_circle`、`progress_activity` 旋转、`schedule`、`terminal`）与规范文本，杜绝任何 emoji 符号。
