# HitlDrawer 标准指标动态联动与比对矩阵特约字段呈现交付报告

## 1. 本次迭代核心治理概述

针对质检业务在多维场景实测核验中暴露的关键交互与数据呈现缺陷，本次改造完成了以下端到端治理：

1. **废除硬编码静态选项，实现标准规则池动态分类联动 (`HitlDrawer.tsx`)**：
   - 彻底废除先前写死的 5 个静态力学指标选项（冲击功、抗拉、屈服、硬度、伸长率）；
   - 在向抽屉下发数据时，由 `WaterfallWorkbench` 提取当前生效标准（如 `NB/T 47019.5-2021`）及材料牌号切片的完整规则池（`candidateRules`）；
   - 抽屉按**化学成分、力学性能、工艺成型、金相组织、耐腐蚀试验、无损探伤、尺寸与表面**等专业门类使用 `<optgroup>` 结构化分组动态渲染；
   - 下拉选项清晰展示：`[中文名称] (属性键) — 标准要求与单位`，辅助质检员精准对齐。

2. **质检审批说明依据处置决策动态联动**：
   - 质检审批说明框彻底废除写死的“人工确认该材料牌号”；
   - 随质检员在【协议特约放行】、【映射对齐至现行标准】、【缺项否决】间切换，实时派生对应的专业合规条款与理由，质检员亦可自由二次编辑。

3. **比对矩阵全景纳管特约放行项与非标裁定项 (`WaterfallWorkbench.tsx`)**：
   - 重构全景比对矩阵数据组装链路：除了标准内置比对项外，全面遍历并纳管 `unmatched_certificate_records` 与 HITL 人工裁定项；
   - **协议特约放行项**：完整呈现质保书原始项目名（如 `Shear Toughness K1C`）、实测值（`85 MPa.m^1/2`）、标准规范（`订货技术协议特约增补条款 (协议放行)`）、判定状态 `✓ PASS`（徽标：`协议特约放行`），并在审核说明栏完整展示质检工程师签署的特批依据；
   - **特种非标否决项**：展示原始项目名与实测值，判定状态 `✗ FAIL`（徽标：`特种非标否决`）；
   - **常规额外报送项**：展示实测值，状态 `- N/A`（徽标：`额外报送`，供参考）。

4. **质保书原始项目名呈现与 Sentinel 内部标识彻底隔离**：
   - **根因治理**：修复 `registerLearnedAlias` 与 `humanReviewNode`，当目标键为 `special_protocol_item` 或 `unrecognized_rejected_item` 时，强制使用 `rawAlias` 作为 `display_name`，杜绝将内部英文键名写入别名知识库；
   - **五级名称反查与防护**：工作台构建了自底向上的五级名称解析防御网（`rec.raw_property_name` 优先 ➔ 非 sentinel `rec.display_name` ➔ `hitlCorrection.corrected_property_keys` 逆向映射 ➔ `activeHitlContext` 待审项目 ➔ `currentBatch.additionalTests` 测量值反查），彻底杜绝在全景矩阵中暴露 `special_protocol_item`，确保直观看到质保书原件项目名称（`Shear Toughness K1C`）。

5. **HITL 字段级裁定与批次级终审权责解耦及非标否决一票穿透**：
   - **变量命名强区隔**：批次终审严格命名为 `humanVerdict`（BATCH-LEVEL FINAL REVIEW ONLY），字段级 HITL 输入纠偏快照统一为 `hitlFieldCorrection`，彻底杜绝概念混淆；
   - **彻底清除越权盖章代码**：`handleResolveHitl` 处理完毕后保持 `humanVerdict: null`（未复核），必须由质检工程师审阅全景比对矩阵后手动在右上角点击【审批通过】或【拒收】；
   - **特种非标否决一票穿透**：当特种非标项被质检员判定为【不予认可 / 缺项否决】时，规则引擎自动将该项作为 `FAIL` 计入决策汇总，系统判定立即呈现为【FAIL 一票否决】（红底警示拦截），流转状态为【系统已拦截待处置】，彻底杜绝任何系统放行假象。
