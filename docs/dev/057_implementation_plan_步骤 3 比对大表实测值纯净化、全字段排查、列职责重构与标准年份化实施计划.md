# 步骤 3 比对大表实测值纯净化、全字段排查、列职责重构与标准年份化实施计划

根据用户对步骤 3 全景比对矩阵中**实测值回归步骤 2 提取原文**、**全字段排查消除伪数据/修约污染**、**偏差量与判定逻辑职责归位**以及**执行标准补齐年份**的明确指令，制定本实施计划。

---

## 一、用户关切与现存缺陷归纳

1. **实测值列被算法/机器状态码污染**：
   - 包含硬编码的修约字符串：如 `0.021 (修约: 0.021%)`；
   - 包含硬编码的验收等级：如超声检测显示 `U2`；
   - 包含后台算法推导过程：如水压替代组显示 `逐根液压/水压试验: PASS (合格); 高等级涡流探伤替代...`；
   - 包含大模型英文机器码：如表面质量显示 `PASS`。
   - **用户原则**：实测值列必须 100% 保持步骤 2 中提取/编辑的原汁原味原文（`measured_value_raw`），即使是“（修约：...）”也绝不应出现在这一列。
2. **“偏差量/吻合度”与“判定逻辑”列职责颠倒**：
   - 原【偏差量 / 吻合度】列装入的是整整一大段判定逻辑与结论说明（`item.message`）；
   - 原【规则依据 / 判定逻辑】列却只孤零零装了一个标准号（`strict_standard_id`），且与前面的【执行标准要求】列中的标准胶囊完全重复冗余。
3. **执行标准要求标签缺失年份**：
   - 当前胶囊标签显示为 `NB/T47019.5`、`GB/T13296`，被正则截断了年份，不够严谨。

## 二、全字段排查清单与整改方案

| 检验分类 | 涉及字段/规则类型 | 当前缺陷现象 | 根治方案 (实测值列展示) |
| :--- | :--- | :--- | :--- |
| **化学成分** | C, Si, Mn, P, S, Cr, Ni, Mo, Ti, N 等定量数值 (`numeric_range`) | 显示 `0.021 (修约: 0.021%)` | 纯净输出步骤 2 提取原文 `record.measured_value_raw`（如 `0.021`），修约说明移入判定逻辑列 |

| **力学性能** | 硬度试验 (`or_choice_group`) | 显示多选一匹配状态 `HV: 143... (合格)` | 纯净输出提取原文（如 `143、145、137、132、140、139 HV1`） |
| **工艺性能** | 压扁试验, 扩口试验 (`dynamic_formula_pass`, `qualitative_and_numeric`) | 若取不到原文退化为 `已报送` 或机器码 | 优先输出提取原文（如 `合格 OK`、`无裂纹`） |
| **金相组织** | 晶粒度评级 (`qualitative_enum` / `enum_acceptance`) | 自动格式化为 `x 级` 覆盖了原文字样 | 优先输出提取原文（如 `6.5 级` 或 `6.5 级 (GB/T 6394-2017)`） |
| **耐腐蚀** | 晶间腐蚀试验 (`qualitative_pass`) | 易退化为机器码 | 优先输出提取原文（如 `合格 OK（5.0%形变）`） |
| **无损探伤** | 涡流探伤 ET, 超声探伤 UT (`enum_acceptance`, `qualitative_pass`) | 超声显示 `U2`，丢掉中文 | 适配层存入原件文本 `batch.process.ndt_ut`（如 `合格 OK`），实测值展示 `合格 OK` |
| **承压致密** | 致密性/水压试验组 (`alternative_group`) | 显示大段二选一推导拼接长串 | 实测值展示质保书实际报送文本（如 `合格 OK`），推导过程全部移入判定逻辑列 |
| **尺寸与表面** | 表面质量与粗糙度, 尺寸检验 (`qualitative_pass`, `geometric`) | 优先读取了大模型英文状态码 `PASS` | 适配层优先取 `t.result`（`合格 OK`），实测值展示 `合格 OK` |
| **扩展追溯** | 施工工程号, 熔炼炉号 (`additional`) | 已展示原始值，保持纯净 | 保持展示原件文本（如 `26715-7053`、`YX2602-2207`） |

## 三、前端全景比对矩阵列重构设计

我们将大表的 7 列职责彻底理顺，确保名副其实、各司其职：

```
+--------+-------------------+------------------------------+--------------------+----------------+----------+--------------------------------+
| 类别   | 检验项目 / 指标    | 执行标准要求 / 条款规范      | 质保书实测值 (原文) | 偏差量 / 吻合度 | 判定状态 | 判定逻辑 / 审核说明            |
+--------+-------------------+------------------------------+--------------------+----------------+----------+--------------------------------+
| 化分   | 碳含量 (C)        | NB/T 47019.5-2021: ≤0.08% ★  | 0.021              | - (达标)       | ✓ PASS   | 实测值满足所有标准严苛要求     |
|        |                   | GB/T 13296-2023: ≤0.08%      |                    |                |          | (GB/T 8170 修约值: 0.021%)     |
+--------+-------------------+------------------------------+--------------------+----------------+----------+--------------------------------+
| 探伤   | 超声检测          | NB/T 47019.5-2021: U2 级 ★  | 合格 OK            | 吻合 (达到U2级) | ✓ PASS   | 依据 GB/T 5777 检验评定合格    |
|        |                   | GB/T 13296-2023: U2 级       |                    |                |          | 达到 U2 级验收要求             |
+--------+-------------------+------------------------------+--------------------+----------------+----------+--------------------------------+
| 金相   | 晶粒度评级        | NB/T 47019.5-2021: ≥7级 ★独占| 6.5 级             | -0.5 级 (未达标)| ✗ 剪刀差 | 基础国标无强制指标，订货行标   |
|        |                   | GB/T 13296-2023: 不考核      |                    |                |          | 独占加严未达标，责任归属订货标 |
+--------+-------------------+------------------------------+--------------------+----------------+----------+--------------------------------+
```

### 关键列调整：
1. **第 3 列【执行标准要求】**：标准代号必须**完整包含年份**（如 `NB/T 47019.5-2021`、`GB/T 13296-2023`），不再截断；
2. **第 4 列【报告测量值 / 实际结果】**：100% 呈现步骤 2 的原始文本（如 `0.021`、`合格 OK`、`143... HV1`），彻底剔除 `(修约: ...)`、`U2` 与替代组内部推导文字；
3. **第 5 列【偏差量 / 吻合度】**：
   - 超标项：以醒目红字展示量化超标差值（如 `+0.006%`、`-0.5 级`、`-15 MPa`）；
   - 合格项：展示量化裕量或简洁的 `- (达标)`；
   - 定性项：展示 `吻合` 或 `符合规范`；
4. **第 7 列【判定逻辑 / 审核说明】**：
   - 承载完整的判定推导逻辑长句（原被错塞在偏差量列的内容）；
   - 展示剪刀差责任归因、法定免检主动报送依据、修约提示等；
   - 彻底删除单纯孤立展示重复标准号的冗余设计。
