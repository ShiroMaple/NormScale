# 工作台步骤 4 隐藏与步骤 3 三联动作按钮走查报告

## 改动概要

1. **步骤 4 入口收敛隐藏**：
   - 底部常驻导航栏（Stepper）由 4 步收拢为 3 步（`1. 上传文档` -> `2. 核对数据` -> `3. 比对标准`），彻底移除了“4. 归档/导出”指示锚点；
   - 垂直滑动受控边界调整为 `goToStep(stepIdx <= 2)`，无法再非预期滑入步骤 4；
   - 移除步骤 3 原“下一步：生成质检报告”按钮。

2. **步骤 3 底部三联动作按钮就绪**：
   - **主要按钮【保存结果】**（位于最右侧高亮位）：
     - 完整提取当前作业会话（Session）的系统与人工检验判定数据，写入浏览器的 `localStorage`（键名 `normscale_saved_sessions`）；
     - 自动联动【历史检验台账】（`AuditLedger`），切换至台账即可实时查看并支持回载；
     - 弹出顶部浮动 Toast 提示：“检验结果已成功保存至本地台账 (Session ID: XXX)”。
   - **次要按钮【保存截图】**：
     - 采用**纯前端原生零依赖**（HTML5 Canvas + SVG foreignObject 离屏栅格化）实现；
     - 完整捕获当前步骤 3 的比对矩阵与判定看板，并生成 2x 视网膜级高清 PNG 图片直接触发浏览器下载；
     - 导出文件名格式为：`NormScale_合规比对结果_{批次号}_{日期}.png`；
     - 包含优雅的“生成截图中...”加载状态与成功 Toast 反馈。
   - **次要按钮【开启新任务】**：
     - 点击后自动静默持久化当前 Session 结果至本地台账；
     - 重置生成全新的 Session 会话实例，自动将当前步骤切换回步骤 1（上传文档）；
     - 弹出 Toast 提示：“已自动归档当前检验结果，已为您开启新任务”。

## 验证结果

- **TypeScript 类型检查**：`pnpm typecheck` (`tsc --noEmit`) **0 错误**通过。
- **本地服务健康检测**：`curl http://localhost:3000` 响应 `200 OK`，热重载正常生效。
