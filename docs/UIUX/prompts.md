# NormScale Google Stitch 界面提示词手册 (Stitch Prompts)

> **使用说明**：本文件包含为 NormScale（准衡）工业质保书智能合规检验系统定制的全套 Google Stitch 提示词（已全部翻译为易于审阅的中文，并保留了必要的样式与专业术语）。
> 系统支持**明暗双模切换**，提示词统一为**默认浅色工业精密风（Default Light Industrial Mode）**，并在导航栏配备明暗模式切换器（☀️/🌙）。
> 业务路由规范：质检工作流统一承载于 `/workbench`，管理分析大盘统一承载于 `/dashboard`。
> 您可以直接复制各节中的提示词粘贴至 [Google Stitch](https://stitch.withgoogle.com/) 的输入框中，生成对应界面的 UI 原型。

## 0. 全局系统设计提示词 (System / Vibe Prompt)

在 Stitch 项目初始化或多屏联动时，可先输入本段作为全局设计基准（或作为 Project Prompt）：

```text
设计一套名为 准衡(NormScale) 的工业级质量证明书（MTC）智能合规检验与比对系统。
风格定位：现代 B2B 工业工程严谨风（Modern Industrial Precision / Engineering Grade），支持明暗双模切换，默认采用清爽高精度的浅色工业配色（Default Light Mode）。

色彩规范（默认浅色模式）：
- 画布主背景采用极浅冷白灰（Slate Mist Light #F8FAFC / #F1F5F9）；
- 卡片与面板容器采用纯白（Pure White #FFFFFF）搭配精致浅灰边框（Border #E2E8F0）与微阴影（shadow-sm）；
- 文本排版：主标题与关键实测数值采用深碳灰（Deep Charcoal #0F172A），次级文本采用灰石色（Slate Neutral #475569）；
- 品牌与主操作强调色为高精度工控蓝（Precision Steel Blue #0284C7 / #0EA5E9）；
- 状态指示色采用鲜明工业规范（浅色底色搭配高对比文字与边框）：
  - 合格 PASS 为翡翠绿（背景 #ECFDF5，文字 #047857，边框 #A7F3D0）；
  - 不合格/拒收 FAIL 为警示猩红（背景 #FEF2F2，文字 #B91C1C，边框 #FECACA）；
  - 漏检/警示 MISSING 为琥珀金（背景 #FFFBEB，文字 #B45309，边框 #FDE68A）；
  - 人机协同挂起 HITL 为紫水晶（背景 #F5F3FF，文字 #6D28D9，边框 #DDD6FE）。

排版与控件规范：
- 清晰无衬线字体，化学元素表、炉批号与数值计算公式使用等宽字体（Monospace）呈现，信息密度高，表格对齐严整；
- 顶部导航栏常驻明暗模式切换开关（☀️ 浅色 / 🌙 深色 Toggle）。
```

## 1. 界面 01：质检工作台 - Step1 质保证书上传与选择 (SCR-01)

* **界面定位**：`/workbench` - 质保证书批量上传、待处理队列与历史质保书库
* **核心用户**：物资采购质检员、收料验收工程师

### Stitch 提示词（直接复制）：

```text
请为 NormScale（工业材料合规检验系统）设计一个 B2B Web 应用界面：

界面结构与组件规范：
1. 顶部全局导航栏（Top Navigation Bar，白底 #FFFFFF，下边框 #E2E8F0）：
   - 左侧：系统 Logo 与名称“准衡 NormScale | 工业质保证书合规检验”；
   - 中间：全局主要功能入口（质检工作台、历史检验台账、标准知识库、系统管理后台）；
   - 右侧：明暗模式切换按钮（当前显示 ☀️ 浅色模式）、当前登录质检员头像与工号（高级质检工程师）。

2. 核心主工作区（上半部分：双列卡片布局）：
   - 区域左侧（占宽 50%）- 上传拖拽区（Upload Dropzone）：
     - 大面积浅灰浅蓝虚线边框拖拽卡片，支持拖入 PDF/图片/Word 格式质保书（最大容量 50MB）；
     - 快捷关联输入项：复选框（应用项目配置而非质保书中提及的执行标准）、所属项目/施工号选择器（例如：区域优化完善(26XXX-0888)）、材料分类（自动检测、无缝钢管、法兰等）。

3. 历史已缓存质保书库（下半部分：快速复用网格）：
   - 标题：“历史缓存质保书（点击复用无需重复上传）”；
   - 采用 4 列响应式卡片网格，平铺展示近期上传过的质保书（例如：“宝钢_S30408_换热管.pdf”、“太钢_06Cr19Ni10_板材.pdf”、“永兴_07Cr19Ni11Ti_无缝管.pdf”等）；

4. 底部常驻步进导航条（Bottom Stepper Bar，白底吸底）：
   - 居中展示 4 阶段步进指示器：
     - `① 上传文档`（当前步骤，高亮激活，带橙色/工控蓝圆形序号）；
     - `② 核对解析结果`（下一步，支持提取数据逐项核查纠错）；

5. 底部右侧主操作按钮组（Action Buttons）：
```
