## 详细功能清单与设计审查点

### 1. [SCR-01] 质检工作台 - Step1 质保证书上传与选择 (`/workbench`)

- [X] **顶部全局导航 (Top Navbar)**：系统 Logo、主导航标签（质检工作台 `/workbench`、历史台账、标准库 `/standards`、系统后台 `/dashboard`）、明暗切换。
- [X] **双列主工作区 (Main Upper Area)**：
  - [X] **左侧拖拽上传区 (Upload Dropzone)**：大面积虚线框（支持 PDF/Word/图片，上限 50MB）、项目施工号绑定、执行标准覆盖勾选、材料品类选择。
  - [X] **右侧待处理队列 (Pending Queue)**：展示待解析质保书列表（文件名、大小、所属项目、删除按钮）或空状态插画。
- [X] **历史已缓存质保书库 (Cached Certificates Grid)**：
  - [ ] 4 列卡片网格，平铺展示历史上传过的质保书（带 PDF 图标、文件名、删除按钮），点击一键加入待处理队列。
- [X] **底部常驻步进条与操作区 (Bottom Bar)**：
  - [X] 4 步骤指示器：`① 上传文档 (激活)` $\to$ `② 核对解析结果` $\to$ `③ 规则合规比对` $\to$ `④ 归档与报告导出`。
  - [X] 操作按钮：“跳过核对，立即比对”次级按钮、“下一步：核对解析结果 →”主按钮。

### 2. [SCR-02] 质检工作台 - Step2 提取结果核对与消歧 (`/workbench/review`)

- [X] **左列 (45%)：原始质保书原件联动预览 (Document Viewer)**：
  - [X] 高清 PDF 渲染，关键受检区域（牌号、炉号、化学成分、力学性能）覆盖半透明彩色 Bounding Box。
  - [X] 与右侧表单联动：表单聚焦时原件对应位置自动高亮居中放大。
- [X] **右列 (55%)：结构化提取字段核查与就地修正 (Extracted Form & Tables)**：
  - [X] 基础元数据核对卡片（供应商、牌号消歧推荐、炉批号、尺寸、执行标准）。
  - [X] 化学成分实测值提取表（带 OCR 置信度标色，低于 85% 醒目预警，支持就地编辑修改）。
  - [X] 力学性能与单位提取卡片（自动识别单位 MPa/psi/kgf 并支持下拉微调）。
- [X] **底部步进与流转操作**：“← 返回上一步修改上传”、“数据无误，开始规则合规比对 →”。

### 3. [SCR-03] 宽屏双列比对决策看板 - Step3 比对标准 (`/workbench/audit/[taskId]`) - 核心旗舰视图

- [ ] **顶部任务信息与操作栏 (Header Summary)**：
  - [ ] 顶部展示任务 ID、供应商名称、炉批号、规格尺寸、声明标准。
  - [ ] 快捷动作按钮：`一键合格放行 (Release)`、`拒收处置 (Reject)`、`特批放行 (Waiver)`。
- [ ] **左列 (45% 宽度)：质保书实测提取数据 (Verified Extracted Data - 唯一真理基准)**：
  - [ ] 面板标注绿色“● 已人工核验 (Verified Data)”认证徽章。
  - [ ] 基础元数据卡片（供应商、消歧牌号 06Cr19Ni10/S30408、炉号、批号、尺寸、执行标准）。
  - [ ] 化学成分实测数据清单（等宽字体展示已核验的 C, Si, Mn, P, S, Ni, Cr, Ti... 实测数值）。
  - [ ] 力学与工艺试验实测清单（抗拉 Rm, 屈服 Rp0.2, 延伸率 A, 硬度 HRB，压扁/晶间/涡流试验合格结论）。
- [ ] **右列 (55% 宽度)：执行标准比对与决策中枢 (Compliance Audit & Decision Engine)**：
  - [ ] **命中规格切片摘要**：如 `GB/T 14976-2012 / S30408`（标注激活的壁厚公差前置条件）。
  - [ ] **综合决策横幅 (Overall Verdict Card)**：大字号合格/拒收卡片（如 `判定结论: ● PASS 全项合格` 或 `✕ FAIL 拒收`）。
  - [ ] **化学成分确定性比对表 (Chemical Audit Matrix)**：
    - [ ] 字段级对照：指标键、实测值、标准范围 [Min, Max]、GB/T 8170 修约判定值、绝对偏差、状态徽章（绿色 ● PASS）。
  - [ ] **力学性能与 AST 动态公式求值区**：
    - [ ] Rm, Rp0.2, 延伸率, 硬度判定区间与状态。
    - [ ] AST 跨元素公式计算展开式（如 $Ti \ge 5 \times (C+N)$）求值结果。
    - [ ] 逻辑替代与免做规则生效状态（如“涡流 E3H 合格 $\to$ 依据标准条款自动免做水压试验”）。
  - [ ] **定性条款与工艺 RAG 复核卡片**（压扁、晶间腐蚀等定性条款语义合格判定）。
  - [ ] **审计轨迹与性能度量折叠流**（展示微秒级判定日志）。
- [ ] **底部吸底步进条**：`① 上传文档 (✓)` $\to$ `② 核对解析结果 (✓)` $\to$ `③ 比对标准 (当前激活)` $\to$ `④ 归档与报告导出`；右侧按钮“← 返回上一步修改数据”、“比对通过，生成质检报告 →”。

  - [ ] “取消并保持挂起”按钮。
  - [ ] “确认修正并恢复流水线 (Resume Audit)”主操作按钮。
